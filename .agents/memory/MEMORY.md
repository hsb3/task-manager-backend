# Project memory index

- [check_app_docs_quotes tokenizes ' as a delimiter](app-docs-quotes-apostrophe-tokenizer.md) — an odd apostrophe count in added app_docs prose re-pairs later quotes and hides registered spans; write apostrophe-free, and extract bodies from a replayed DB, never by grepping migrations
- [The app_docs seed is its own only source](app-docs-seed-is-its-own-only-source.md) — replaying without the generated seed migration yields zero rows, so every replay-based app_docs gate compares the file to itself; a one-byte prose edit is invisible to the whole battery
- [Battery hang on a surviving room](battery-hang-surviving-room.md) — `stop_room` kills then waits, so a legacy server that survives stalls the battery; kill that pid by number
- [Local-first testing](feedback-local-first-testing.md) — test against local rooms/dev first; prod gates only for claims about prod itself
- [Owner design rulings](feedback-owner-design-rulings.md) — names are display-only never keys (incl. name-derived slugs); no vestigial fields, delete column+index+hooks+tests together
- [Schema-derived OpenAPI pattern](feedback-schema-derived-openapi-pattern.md) — no OpenAPI export? generate from schema truth: deterministic script + --check drift gate
- [A fresh worktree lacks gitignored files](fresh-worktree-lacks-gitignored-files.md) — copy `.env` in and set `PB_BIN`; the "forks from the last pushed commit" half is unconfirmed
- [FSEvents hits each new watcher](fsevents-stale-edit-hits-new-watcher.md) — a room booted right after a `pb_hooks/` touch can restart just after going healthy; settle then re-check health; reproduce only from a separate OS process
- [Generated artifacts merge as binary](generated-artifacts-merge-binary.md) — a conflicted generated file keeps OURS with NO markers, so resolve by regenerating and never `git add`; every merge into main re-conflicts the next PR's artifacts, one rebase per sibling landing
- [Never symlink into a worktree](never-symlink-into-a-worktree.md) — a TS clean-room copy keeps a symlinked source as a symlink and its rmSync deletes real files through it; copy scratch dirs, never link
- [Node cpSync dereference skips entries](node-cpsync-dereference-skips-entries.md) — `cpSync({dereference:true})` still copies a symlinked ENTRY as a symlink (Node 26), so an isolated scratch copy can write through to the real tree; refuse symlinks by name
- [Container-held items hide their project](pb-container-held-items.md) — a project-less item lands in the hidden shadow project (decision-052), so `expand=project` is empty on an item that has one
- [PB DynamicModel fractional template](pb-dynamicmodel-fractional-template.md) — an integer template scans a fractional value into an int and throws, so a committed create returns HTTP 400; write the template fractional and use the array form
- [PB hook .bind form panics under concurrency](pb-hook-bind-form-panics-under-concurrency.md) — `onRecordCreateRequest().bind({...})` is called with no event under concurrent creates and items commit unkeyed; `e.app = txApp` leaks the transaction to other requests; plain form, never reassign e.app
- [PB hook order across files](pb-hook-order-across-files.md) — an untagged hook and a tagged chain-ender in another file run in no stable order per boot; make the dependency explicit and prove it across repeated boots
- [PB rules are per operation](pb-rules-are-per-operation.md) — a peer 404'd on GET still got 200 and the full body from a blind PATCH by id; put the privacy predicate on every operation
- [A view field cannot be hidden on PB 0.40.4](pb-view-field-hidden-unsupported.md) — `hidden` silently reads back false on a VIEW field (base-collection fields work), so a hide-this-column design has no platform flag to lean on; and `$app.canAccessRecord` re-queries the persisted row by id, so an unsaved record fails every rule
- [Proofs must be falsifiable](proofs-must-be-falsifiable.md) — waves shipped green proofs of untrue things; mutation-prove every assertion RED before it counts, and pin a known bug with an explicit assertion, never an expected-failure marker
- [Each Railway custom domain gets its own CNAME](railway-custom-domain-unique-cname.md) — even re-adding the same hostname to another service issues a new target; update DNS every time
- [Confirm a Railway deploy by sha](railway-deploy-confirm-by-sha.md) — `RUNNING` means live and `railway redeploy` prints nothing on success; poll the commit sha to `SUCCESS`
- [Railway env duplication traps](railway-env-duplication-traps.md) — deploy branch is a deployment trigger, not a service field; `--service-config <name>` and `connect-service-source` both fail silently or globally; GraphQL needs a User-Agent
- [S3 backup-bucket ops](s3-backup-bucket-ops.md) — curl sigv4 recipe; %40-encode @-keys on DELETE or 403; cron actually 18:08 UTC; pb-files is the separate uploads bucket since PBTT-390
- [Scratch dirs must be unique](scratch-dirs-must-be-unique.md) — `PB_PORT_OFFSET` separates ports, not directories; a fixed scratch name under a shared temp root let one agent delete another's live rooms; `mktemp -d`
- [Universal guards need a touches predicate](universal-guard-needs-touches-predicate.md) — without `touchesScope` a universal guard throws on already-bad rows and the leaver sweep strands every remaining assignee (0 vs 5)
